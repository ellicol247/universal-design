Semantic Basics

Semantic HTML elements provide meaning to the web page structure, making it easier for both developers and browsers to understand the content. Some common semantic elements include:

  • <header>: Represents introductory content or a set of navigational links.
  • <nav>: Defines a section of navigation links.
  • <main>: Represents the main content of the document.
  • <section>: Defines a section in a document.
  • <article>: Represents a self-contained piece of content.
  • <aside>: Contains content that is tangentially related to the main content.
  • <footer>: Represents footer information for its nearest sectioning content or root element.

Using semantic elements improves accessibility, SEO, and overall user experience.
